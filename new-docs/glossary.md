# Glossary

```{glossary}
XMM-Newton
: ESA's X-ray Multi-Mirror Mission space observatory, carrying the EPIC (`pn`, `mos1`, `mos2`) X-ray cameras and Reflection Grating Spectrometers (RGS).

Chandra
: NASA's flagship high-angular-resolution X-ray observatory, carrying the ACIS and HRC instruments.

eROSITA
: The extended Roentgen Survey with an Imaging Telescope Array aboard the SRG observatory, comprising seven telescope modules (`tm1`–`tm7`).

ObsID
: Observation identifier uniquely identifying a single telescope pointing or survey sky tile.

XSPEC
: The X-ray Spectral Fitting Package distributed as part of NASA HEASoft.
```
