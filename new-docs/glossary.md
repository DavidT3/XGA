# Glossary

```{glossary}
XMM-Newton
: ESA's X-ray Multi-Mirror Mission space observatory, carrying the EPIC (`pn`, `mos1`, `mos2`) X-ray cameras and Reflection Grating Spectrometers (RGS).

Chandra
: NASA's flagship high-angular-resolution X-ray observatory, carrying the ACIS and HRC instruments.

eROSITA
: The extended Roentgen Survey with an Imaging Telescope Array aboard the SRG observatory, comprising seven telescope modules (`tm1`–`tm7`).

eRASS
: The eROSITA All-Sky Survey, divided into overlapping sky tiles identified by 6-digit tile IDs.

ObsID
: Observation identifier uniquely identifying a single telescope pointing or survey sky tile.

XSPEC
: The X-ray Spectral Fitting Package distributed as part of NASA HEASoft.

HEASoft
: The High Energy Astrophysics Software suite maintained by NASA's HEASARC, which includes XSPEC, FTOOLS, and XSELECT.

SAS
: The XMM-Newton Science Analysis System used to reduce XMM-Newton data and generate science products.

CIAO
: The Chandra Interactive Analysis of Observations software package distributed by the Chandra X-ray Center (CXC).

CALDB
: Calibration Database containing mission- and instrument-specific calibration files (particularly for Chandra CIAO and HEASARC missions).

eSASS
: The eROSITA Science Analysis Software System developed by the eROSITA consortium at MPE.

DAXA
: The Democratised Archival X-ray Astronomy Python package (`daxa`), designed to acquire, organize, and clean multi-mission X-ray astronomy archives.
```
