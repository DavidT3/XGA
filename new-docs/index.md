**X-ray: Generate and Analyse (XGA)** {cite:p}`Turner2022XGA` is a Python package designed to generate and analyse X-ray astronomy data products for individual sources and large samples across multiple X-ray missions ({term}`XMM-Newton`, {term}`Chandra`, and {term}`eROSITA`).

```{note}
This directory (`new-docs/`) houses the upcoming Jupyter Book 2 / `mystmd` documentation for XGA while the overhaul is in progress. Executable tutorials and case studies in this directory are authored as text-based MyST Markdown (`.md`) notebooks using Jupytext frontmatter rather than binary `.ipynb` files.
```
